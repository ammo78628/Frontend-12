# Difference Between `pop()`, `push()`, `shift()`, and `unshift()`

Array methods for adding and removing elements:

- `.pop()` removes an element from the end of an array.
- `.push(value)` adds an element to the end of an array.
- `.shift()` removes an element from the start of an array.
- `.unshift(value)` adds an element to the start of an array.
